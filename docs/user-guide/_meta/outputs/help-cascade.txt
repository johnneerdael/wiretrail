Earliest failure and downstream failure cascades

Usage: wiretrail <FILE> cascade [OPTIONS]

Options:
      --window-ms <WINDOW_MS>
          Window (ms) to attribute downstream failures to a trigger [default: 5000]
      --min-downstream <MIN_DOWNSTREAM>
          Minimum downstream failures to report a cascade [default: 3]
      --json
          Emit machine-readable JSON
      --top <TOP>
          Max items per list (top-N) [default: 10]
      --filter <FILTER>
          Filter clauses, e.g. --filter "host:api.foo.com status:>=400"
      --config <CONFIG>
          Path to a wiretrail.yaml config (default: ./wiretrail.yaml if present)
      --unsafe-include-secrets
          Show raw secret values (auth headers, tokens, bodies) instead of redacting
  -h, --help
          Print help
